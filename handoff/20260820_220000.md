## Cosa è cambiato

### Fix USB Host Reset-Loop (v6.12.104)

Identificata e risolta la causa del reset-loop USB host su Tegra30 (OUYA) che si manifestava con kernel ≥6.6.2.

**Root cause:** Il commit `38a41a0c0272` ("usb: chipidea: Fix DMA overwrite for Tegra") ha modificato il meccanismo di bounce buffer DMA in `drivers/usb/chipidea/host.c`, causando instabilità del controller USB su Tegra30.

**Soluzione:** 2 patch:
1. `0001-usb-chipidea-tegra-remove-REQUIRES_ALIGNED_DMA.patch` — rimuove `CI_HDRC_REQUIRES_ALIGNED_DMA` da `tegra30_ehci_soc_info`
2. `0002-usb-chipidea-host-revert-DMA-alignment-to-v6.6.1.patch` — riporta il codice DMA alignment a v6.6.1

**Test eseguiti:**
- v6.6.1: funziona senza patch ✓
- v6.6.2: reset-loop senza patch, funziona con patch ✓
- v6.12.104: reset-loop senza patch, funziona con patch ✓
